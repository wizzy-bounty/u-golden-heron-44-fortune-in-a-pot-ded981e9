Fortune in a Pot — one kind, funny fortune for a houseplant, in a single line of at most 120 characters. The program writes the fortune to `/output/entry.txt`.

> Your sunbeam has pencilled you in for a growth spurt, and your keeper takes the credit. Let them — you know the truth.

## Run it

```sh
python3 main.py
```

Deterministic, standard library only, no network. The output is a single line of 118 characters with no trailing newline.
